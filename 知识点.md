3.绑定对象

在ItemsSource绑定对象，在这个标签内的Binding 都指向这个对象内的变量

如果要指向vm的变量，要

```
Command="{Binding DataContext.ConnectCommand,
          RelativeSource={RelativeSource AncestorType=Window}}"
```

| 写法                                 | 含义                                      |
| ------------------------------------ | ----------------------------------------- |
| `AncestorType=ListBox`               | 找最近的 `ListBox` 祖先                   |
| `AncestorType=DataGrid`              | 找最近的 `DataGrid` 祖先                  |
| `AncestorType=UserControl`           | 找最近的 `UserControl` 祖先               |
| `AncestorType=Window`                | 找最近的 `Window` 祖先                    |
| `AncestorType=Grid, AncestorLevel=2` | 忽略第 1 个 `Grid`，找第 2 个 `Grid` 祖先 |

### ScrollViewer自动滚动

参考：[Wpf自动滚动效果 - 朋克 - 博客园](https://www.cnblogs.com/punkrocker/p/11261295.html)

[WPF 滚动视图(ScrollViewer)学习笔记_wpf scrollviewer-CSDN博客](https://blog.csdn.net/2403_87711722/article/details/154981628)

前端代码

1.指定查看器的ScrollChanged

2.对ScrollViewer进行命令，后端可以进行操控

3.用tag记录鼠标悬停，悬停时不滚动

```
 <ScrollViewer
     x:Name="Readscroll"
     Margin="6"
     HorizontalScrollBarVisibility="Auto"
     ScrollChanged="ReadContent_ScrollChanged"
     VerticalScrollBarVisibility="Auto">
     <ScrollViewer.Style>
         <Style TargetType="ScrollViewer">
             <Setter Property="Tag" Value="2" />
             <Style.Triggers>
                 <Trigger Property="IsMouseOver" Value="True">
                 	<Setter Property="Tag" Value="1" />
                 </Trigger>
             </Style.Triggers>
         </Style>
     </ScrollViewer.Style>
     
     <TextBlock
         FontFamily="Consolas"
         FontSize="11"
         Foreground="#DCEBF7"
         Text="{Binding ReadContent}"
         TextWrapping="NoWrap" />
 </ScrollViewer>
```

后端代码

```
public void ReadContent_ScrollChanged(object sender, ScrollChangedEventArgs e)
{
    if (Readscroll.Tag.ToString() == "1") return;
    double verticalOffset = e.VerticalOffset;//滚动位置
    double extentHeight = e.ExtentHeight;//内容总高度
    double viewportHeight = e.ViewportHeight;//可视内容高度
    double scrollableHeight = extentHeight - viewportHeight;
    if (scrollableHeight >= verticalOffset + 10)
    {
    	//通过x：name，指定滚动位置
        Readscroll.ScrollToVerticalOffset(scrollableHeight);
    }

}
```



## 后台语法

### 数据绑定

#### 1 set，get双向绑定

需要继承INotifyPropertyChanged类

```
private string _Username;
public string Username { get => _Username; set => SetProperty(ref _Username, value); }
private bool _IsSave;

public class ViewModelBase : INotifyPropertyChanged
{
    public event PropertyChangedEventHandler PropertyChanged;
    public void OnPropertyChanged(string propertyName)
    {
        PropertyChanged?.Invoke(this, new PropertyChangedEventArgs(propertyName));
    }
    protected bool SetProperty<T>(ref T storage, T value, [CallerMemberName] string propertyName = null)
    {
        if (Equals(storage, value)) return false;

        storage = value;
        OnPropertyChanged(propertyName);
        return true;
    }
}
```

#### 3 lblTitle别名绑定

```
public new string Title
{
    get { return this.lblTitle.Text; }
    set { this.lblTitle.Text = value; }
}
```

不是双向绑定

1. 如果后台代码修改了 `Title`（触发了 `set`），它**确实**会更新界面（因为代码里写了 `this.lblTitle.Text = value`）。
2. 但如果界面上有输入框（`TextBox`）绑定了这个 `Title`，当用户改了输入框的内容时，**界面不会通知后台**（因为没有属性变化通知事件），后台的 `Title` 依然是旧的。

#### ListBox切换回滚

ListBox切换时，特殊情况对切换进行阻止并回滚

 WPF 的绑定表达式在把值推送到源的途中会把自己标记为「正在传输」，这期间源发出的属性变更通知会被直接忽略（用来防止无限回环）。

不能再同一个方法里，对值多次切换，后续切换会被拦截无视

```
public string GetWayIp
{
    get => _GetWayIp;
    set
    {
        AppendLog($"----------------------------------------------------------");
        AppendLog($"网关切换：{_GetWayIp} => {value},当前网关状态：{IsSwitch}");
        if (_isRollingBack)
        {
            AppendLog($"网关回滚中。。。。。");
            SetProperty(ref _GetWayIp, value, true);
            return;
        }

        if (IsSwitch)
        {
            AppendLog($"网关正在切换，回退到 {oldIP}");

            // 已经在排队回滚了，直接忽略这次点击（_GetWayIp 仍是旧值）
            if (_rollbackPending) return;
            _rollbackPending = true;

            // 先悄悄收下这次传进来的值（不通知），
            // 否则回头把旧值写回来时会被 SetProperty 的"值相同"判断挡掉
            _GetWayIp = value;

            // 关键点：这次赋值正卡在"界面 SelectedValue -> 属性"的传输过程中，
            // 此时直接 OnPropertyChanged 会被绑定引擎当成回环丢弃，界面高亮收不回去。
            // 必须等这一次传输处理完（推到下一个 Dispatcher 消息）再通知界面切回旧网关。
            Application.Current.Dispatcher.BeginInvoke(new Action(() =>
            {
                _isRollingBack = true;
                GetWayIp = oldIP;                 // 触发通知，把 SelectedValue 拉回旧网关
                GetWayItem = GetIpModel(oldIP);   // SelectedItem 一并同步
                _isRollingBack = false;
                _rollbackPending = false;

                MessageView.ShowWaring("还有未完成的操作！");
            }));

            return;
        }

        if (SetProperty(ref _GetWayIp, value) && !string.IsNullOrEmpty(value))
        {
            oldIP = value;
            AppendLog($"网关回切换成功。。。。。");
            DefaulConfig.GetwayIp = value;
            GetWayItem = GetIpModel(value);
            _ = SwitchGetWayAsync(value);

        }

    }
}
```
