### Binding 绑定数据

1.StaticResource静态数据



2.通过名称直接绑定vm中的属性



3.绑定对象

在ItemsSource绑定对象，在这个标签内的Binding 都指向这个对象内的变量

如果要指向vm的变量，要

```
Command="{Binding DataContext.ConnectCommand,
          RelativeSource={RelativeSource AncestorType=Window}}"
```

| 写法                                 | 含义                                      |
| ------------------------------------ | ----------------------------------------- |
| `AncestorType=ListBox`               | 找最近的 `ListBox` 祖先                   |
| `AncestorType=DataGrid`              | 找最近的 `DataGrid` 祖先                  |
| `AncestorType=UserControl`           | 找最近的 `UserControl` 祖先               |
| `AncestorType=Window`                | 找最近的 `Window` 祖先                    |
| `AncestorType=Grid, AncestorLevel=2` | 忽略第 1 个 `Grid`，找第 2 个 `Grid` 祖先 |

### 外层点击效果未触发

点击按钮后，外层点击效果未触发

xaml代码

```
<ListBox.ItemContainerStyle>
    <Style TargetType="ListBoxItem">
        <!-- ... 你原有的 Width、IsEnabled 绑定等 Setter ... -->
        
        <!-- ⭐ 核心修复：通过预览事件强制选中 -->
        <EventSetter Event="PreviewMouseLeftButtonDown" 
                     Handler="ListBoxItem_PreviewMouseLeftButtonDown" />
        
        <!-- ... 你原有的 Template 和 Triggers ... -->
    </Style>
</ListBox.ItemContainerStyle>
```

后台代码

```
private void ListBoxItem_PreviewMouseLeftButtonDown(object sender, MouseButtonEventArgs e)
{
    if (sender is ListBoxItem item && !item.IsSelected)
    {
        // 手动设置选中状态
        item.IsSelected = true;
        
        // 确保键盘焦点也同步过来（支持后续键盘上下键切换）
        item.Focus();
    }
}
```



## 后台语法

### 数据绑定

#### 1 set，get双向绑定

需要继承INotifyPropertyChanged类

```
private string _Username;
public string Username { get => _Username; set => SetProperty(ref _Username, value); }
private bool _IsSave;

public class ViewModelBase : INotifyPropertyChanged
{
    public event PropertyChangedEventHandler PropertyChanged;
    public void OnPropertyChanged(string propertyName)
    {
        PropertyChanged?.Invoke(this, new PropertyChangedEventArgs(propertyName));
    }
    protected bool SetProperty<T>(ref T storage, T value, [CallerMemberName] string propertyName = null)
    {
        if (Equals(storage, value)) return false;

        storage = value;
        OnPropertyChanged(propertyName);
        return true;
    }
}
```



#### 2 x:name 双向绑定

限制：只能在view对于cs文件中使用

有点：不需要再后台命名，可以直接使用



#### 3 lblTitle别名绑定

```
public new string Title
{
    get { return this.lblTitle.Text; }
    set { this.lblTitle.Text = value; }
}
```

不是双向绑定

1. 如果后台代码修改了 `Title`（触发了 `set`），它**确实**会更新界面（因为代码里写了 `this.lblTitle.Text = value`）。
2. 但如果界面上有输入框（`TextBox`）绑定了这个 `Title`，当用户改了输入框的内容时，**界面不会通知后台**（因为没有属性变化通知事件），后台的 `Title` 依然是旧的。

### 调出弹窗返回结果的弹窗

view.ShowDialog()

​	阻塞代码执行：调用后，后面的代码会暂停，直到这个窗口关闭才会继续执行。
​	禁用父窗口：用户无法点击或操作主窗口，必须先处理完这个弹窗。

this.DialogResult = true/false;

​	它的作用是**设置当前窗口的“返回结果”，并自动关闭窗口**。

```
var view = new DMMessageBox();
bool? result = view.ShowDialog(); // 代码在这里暂停，等待用户操作

private void OkButton_Click(object sender, RoutedEventArgs e)
{
    this.DialogResult = true; // 返回 true，并自动关闭窗口
}

private void CancelButton_Click(object sender, RoutedEventArgs e)
{
    this.DialogResult = false; // 返回 false，并自动关闭窗口
}
```
